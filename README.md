# Sanal Krishna Kumaran — Portfolio

1. Extract the ZIP.
2. Create a public GitHub repository called `YOURUSERNAME.github.io` (or any project repository).
3. Upload all files from the ZIP root to the repository root and commit.
4. Open Settings → Pages → Build and deployment → Deploy from a branch. Select `main`, `/ (root)`, Save.
5. Once published, open the URL displayed in Settings → Pages.

For local preview, open index.html. No dependencies or build process. The PDF and workbook are included and linked using relative paths. All project outcomes are simulated.
